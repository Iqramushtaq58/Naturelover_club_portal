# Nature Lover Club (Laravel Project)

A web portal built with Laravel for managing club members, events, and profiles. This project is designed as a portfolio example and demonstrates user registration, login, profile management, event management, and admin features.

## 🖥️ Features
 User Registration & Login  
 Profile Management (view & update)  
 Events Management (view events, join events)  
 Admin Dashboard (manage members & events)  
 File Uploads (profile pictures & event images)  

## 🛠️ Technologies Used
Backend: Laravel (PHP)  
Frontend:HTML, CSS, Bootstrap 5, JavaScript  
Database: MySQL  
Version Control: Git & GitHub  

##  Project Structure
app/ → Controllers, Models  
routes/ → Web routes  
resources/views/ → Blade templates (frontend)  
public/ → CSS, JS, images  
database/ → Migrations & seeds
